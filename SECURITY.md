# Security Policy

`mcp-guard` is a security tool, so reports about incorrect detection, missed secrets, unsafe output, or publishing problems are welcome.

## Reporting A Vulnerability

Do not open a public issue containing real secrets.

Use GitHub's private vulnerability reporting if available:

```text
https://github.com/chiragborse1/mcp-guard/security/advisories/new
```

If you need to include an example, use fake values only. Mask any sensitive values before sharing logs, screenshots, SARIF, or JSON output.

## Supported Versions

The latest release is the supported version. Patch releases may be made for security fixes, false-positive reductions, or packaging issues.
